# Normativa · Legislation

Gli atti normativi statali, una cartella per tipo di atto (`normativa/<tipo>/<anno>/<numero>/`), un file per articolo; la Costituzione è in [`costituzione/`](../costituzione/). Fino al 17 novembre 2026 queste cartelle erano nella radice del repository; [`data/paths.json`](../data/paths.json) indica la vecchia posizione di ciascuna.
